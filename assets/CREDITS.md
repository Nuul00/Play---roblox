# Pet model sources

The game includes geometry from these free Roblox Creator Store models:

- [Pets pet pack simulator pets low poly pack](https://create.roblox.com/store/asset/14776469645/Pets-pet-pack-simulator-pets-low-poly-pack), by **Fbxies**. Bear, cat and bunny models.
- [Pet System](https://create.roblox.com/store/asset/12731405251/Pet-System), by **Sub2HTR / HowToRoblox**. Additional animal and fantasy pet geometry.
- [Synty Nature Pack](https://create.roblox.com/marketplace/asset/6933438443/Synty-Nature-Pack), published by **Roblox**, officially licensed for Roblox games. Tree geometry is loaded by the Environment script; the authored trees remain if the service is unavailable.

Imported in Roblox Studio on November 1, 2026. The local library contains 23 source models. Gameplay scripts, remotes, humanoids, sounds and interaction objects from the source packs are excluded. Only the visual models are used; this project's own server handles all currency, eggs and progression.

`PetAssets.xml` is the Studio-exported geometry library embedded by the place builder. Meshes and textures reference their Roblox asset IDs. Their availability is still governed by Roblox asset permissions. New names, rarity definitions, themed catalog entries and multipliers belong to this game's configuration; multiple catalog entries can use variants of the same base species.
