# Монеты и скорость — первая Roblox-игра

## Текущая версия: мастерская и яйцо

Открывайте **CoinSprint_Shops.rbxlx** и нажимайте F5. В каждом мире стоит один прилавок с навесом. Продавец загружает аватар профиля **1361632228** (настройка `GameConfig.ShopkeeperUserId`). Если загрузка Roblox временно недоступна, остаётся видимый манекен.

Подойдите к прилавку и нажмите **E**: откроется единое меню **скорости, магнита и дохода** с текущими параметрами и ценами. Открытие меню бесплатно. Доход стоит 15, 30, 45 и далее, каждый уровень прибавляет 0,25 к множителю: ×1 → ×1,25 → ×1,5. Он умножается на бонус питомца. Максимум — 10 уровней дохода.

Справа от мастерской находится отдельный стенд с объёмным вращающимся яйцом. Нажмите E, посмотрите цену и шансы и выберите **«Открыть яйцо»**. Стоимость 25 монет; шансы: лисёнок 60%, кот-бот 30%, дракон 10%. После покачивания яйца появляется 3D-модель результата. Повторы учитываются в коллекции, автоматически сопровождает самый сильный из открытых питомцев. Прежняя покупка питомцев по очереди заменена яйцом.

Текущий проект включает шесть скриптов: GameConfig и PetVisuals (ModuleScript в ReplicatedStorage), GameServer (Script в ServerScriptService), GameHUD, GameEffects и ShopUI (LocalScript в StarterPlayerScripts). PetVisuals хранит общие 3D-модели для спутников и открытия яйца — сюда позже можно поставить ваши собственные модели.

Проверочный сценарий этой версии находится в `tests/ShopsPlaytest.luau`. Предыдущие разделы ниже сохраняют описание прошлых этапов; актуальные взаимодействия — мастерская и яйцо из этого раздела.

## Новая версия: спидометр, питомцы и магнит

Откройте **CoinSprint_Upgrades.rbxlx** через File → Open from File и нажмите F5. Оба мира видны в редакторе. При проверке выбирайте именно новый файл: ранее открытое окно Studio не перечитывает изменения на диске автоматически.

- Счётчик монет сохранил прежний вид. Отдельный спидометр справа показывает фактическую скорость; ниже подписаны купленный предел и уровень. В покое стрелка на нуле.
- Синий магазин продаёт скорость: цены 10, 20, 30, 40, 50.
- Фиолетовый магазин продаёт магнит: первое улучшение стоит 5, следующие — 10, 15 и далее. Радиус начинается с 5 студов и растёт на 10% за уровень, максимум 10 уровней. Светящееся кольцо показывает дальность сбора. Это рост радиуса, а не площади.
- Оранжевый магазин продаёт питомцев по очереди: лисёнок ×1,5 за 25; кот-бот ×2 за 75; дракон ×3 за 200. Активен один питомец; новая покупка заменяет его более сильным. После покупки питомец следует за персонажем. Множители не складываются.
- Монета острова даёт 5, монета Неонграда — 10; питомец умножает эту награду. Поэтому с лисёнком получаются 7,5 и 15 соответственно. Баланс поддерживает дробные монеты.
- Портал справа от старта ведёт в Неонград после трёх улучшений скорости (скорость 28). Обратный переход бесплатный. Покупка в любом мире меняет общие личные характеристики игрока.
- Все покупки выполняются клавишей E или нажатием подсказки рядом с магазином. Деньги, скорость, магнит и питомец остаются после гибели, но сбрасываются при выходе.

Для ручной проверки соберите одну монету, купите магнит за 5 и сравните кольцо. Накопите 25, купите лисёнка и проверьте прибавку 7,5 за монету. Затем купите три улучшения скорости и войдите в портал. Скрипт `tests/UpgradesPlaytest.luau` предназначен только для тестовой Command Bar на вкладке Server: он выдаёт временные деньги и подводит персонажа к следующим проверкам.

Обновлённый проект содержит **четыре** скрипта: прежние GameConfig, GameServer и GameHUD плюс **LocalScript GameEffects** в StarterPlayer → StarterPlayerScripts. GameEffects рисует питомцев и кольцо; награды и покупки рассчитывает GameServer. Для ручной установки этой версии скопируйте карту CoinSpeedWorld из готового проекта: сервер теперь ожидает обе сохранённые зоны. Старые инструкции ниже описывают устройство первой версии.

Небольшая игра для вас с другом. Игрок бегает по арене, касается золотых монет и покупает скорость у синего магазина. Карта уже сохранена в проекте и видна до запуска, а интерфейс появляется при Play.

Готовый проект проверен в Roblox Studio, включая режим двух игроков. Подробные результаты — в [TESTING.md](TESTING.md).

## Самый быстрый запуск

1. Откройте Roblox Studio.
2. Выберите **File → Open from File…** (в некоторых версиях **Open…**) и откройте `CoinSprint.rbxlx` из этой папки.
3. Уже до запуска видна арена. Нажмите **F5** или кнопку **Play / Test**, чтобы управлять персонажем.
4. Управляйте персонажем клавишами **WASD**, прыгайте **Space**. Коснитесь двух золотых монет.
5. Подойдите к синему **МАГАЗИНУ СКОРОСТИ** и нажмите **E**, когда появится подсказка. На телефоне нажимайте саму подсказку.
6. Для остановки нажмите **Shift+F5** или **Stop**.

Готовый файл уже содержит три скрипта и карту в `Workspace → CoinSpeedWorld`. Повторно добавлять их в этот проект не нужно. Если открыта старая пустая версия проекта, откройте обновлённый файл заново. Для удобства та же версия с видимым миром доступна в `CoinSprint_World.rbxlx`.

Чтобы приблизить мир, раскройте `Workspace`, выделите `CoinSpeedWorld` и нажмите **F**. Внутри находятся `Floor` (пол), стены, `Start` (старт), `SpeedShop` (магазин) и `Coin_1`–`Coin_15` (монеты). При остановленном тесте их можно передвигать и перекрашивать обычными инструментами Studio. Имена сохраняйте: по ним скрипт находит объекты.

## Что уже умеет игра

- На арене расположены **15 монет**. Одна монета даёт **5** игровой валюты.
- Собранная монета исчезает для всех и возвращается через **5 секунд**. Если два игрока касаются одной монеты, награду получает один из них.
- У каждого игрока свой баланс и свой уровень скорости.
- Магазин продаёт **5 улучшений**, каждое прибавляет **4** к скорости.
- Интерфейс показывает баланс, скорость, уровень и цену следующего улучшения.
- При нехватке монет магазин объясняет, сколько ещё нужно собрать.
- После гибели персонажа купленная скорость остаётся до конца текущего подключения.

| Купленный уровень | Скорость | Цена перехода на этот уровень |
| --- | --- | --- |
| 0 — начало игры | 16 | Бесплатно |
| 1 | 20 | 10 монет |
| 2 | 24 | 20 монет |
| 3 | 28 | 30 монет |
| 4 | 32 | 40 монет |
| 5 — максимум | 36 | 50 монет |

Это обычная валюта внутри игры, не Robux. **Сохранения между заходами пока нет:** выход из игры, переподключение или остановка теста обнуляют деньги и улучшения. Никаких API-ключей или дополнительных плагинов для запуска не нужно.

## Если хотите вставить скрипты самостоятельно

Этот способ нужен для нового проекта **Baseplate**, если вы хотите разобраться в устройстве игры. Используйте его вместо открытия готового `CoinSprint.rbxlx`.

Остановите тест перед редактированием. Откройте панели **Explorer** (список объектов), **Properties** (их настройки) и **Output** (сообщения и ошибки) через меню **Window**; в старом интерфейсе они могут быть в **View**.

В Explorer создайте следующие объекты. Для этого нажмите **+** рядом с нужной папкой или нажмите на неё правой кнопкой и выберите **Insert Object**.

```text
ReplicatedStorage
└── GameConfig                    ModuleScript

ServerScriptService
└── GameServer                    Script

StarterPlayer
└── StarterPlayerScripts
    └── GameHUD                   LocalScript
```

| Где создать объект | Какой тип выбрать | Как назвать | Откуда скопировать весь код |
| --- | --- | --- | --- |
| `ReplicatedStorage` | **ModuleScript** | `GameConfig` | `src/ReplicatedStorage/GameConfig.luau` |
| `ServerScriptService` | **Script** | `GameServer` | `src/ServerScriptService/GameServer.server.luau` |
| `StarterPlayer → StarterPlayerScripts` | **LocalScript** | `GameHUD` | `src/StarterPlayer/StarterPlayerScripts/GameHUD.client.luau` |

Дважды нажмите на созданный скрипт, выделите его начальный код (**Ctrl+A**) и замените содержимым соответствующего файла. Имена в Studio вводите **без** `.luau`, `.server` и `.client`. Большие и маленькие буквы важны.

Если в шаблоне уже есть `SpawnLocation`, удалите **только этот стартовый SpawnLocation** в вашем новом проекте: наша игра создаёт собственный. Обычный Baseplate можно оставить под ареной. Проверьте, что `GameServer` всего один и что у Script не включён `Disabled` (в версиях Studio с `Enabled` оно должно быть включено). Нажмите F5.

## Проверка по шагам

Начните новый тест, чтобы баланс был равен нулю.

| Действие | Что должно произойти |
| --- | --- |
| Запустить игру | Видны арена, золотые монеты, синий магазин и интерфейс. Баланс 0, скорость 16, уровень 0/5. |
| С балансом 0 дойти до магазина сбоку, обходя монеты, и нажать E | Сообщение «Не хватает монет». Баланс и скорость прежние. |
| Коснуться одной монеты | Баланс 5. Монета исчезает; она не начисляет награду за каждую часть тела. |
| Подождать около 5 секунд рядом, не касаясь монеты | Монета снова видна. Её можно собрать ещё раз. |
| Иметь ровно 10 монет и купить первое улучшение | Баланс 0, скорость 20, уровень 1/5. Следующая цена — 20. |
| При балансе 5 попытаться купить улучшение за 20 | Баланс 5 и уровень 1 остаются прежними; нужно ещё 15 монет. |
| Купить все 5 улучшений | Скорость 36; интерфейс сообщает о максимуме. Всего потребуется 150 монет. |
| Нажать E после максимального уровня | Деньги не списываются, уровень не растёт. |
| Сбросить персонажа через меню Roblox → Reset Character | После появления скорость восстановится, баланс и уровень останутся. |
| Остановить тест и запустить заново | Баланс 0, скорость 16. Это ожидаемо для версии без сохранений. |

## Проверка двух игроков на одном компьютере

Другу не обязательно быть рядом: Studio умеет запускать два тестовых окна на вашем компьютере.

1. Остановите обычный тест.
2. В списке режимов тестирования выберите **Server & Clients** и **2** клиента. В старом интерфейсе это может быть вкладка **Test → Clients and Servers**.
3. Нажмите кнопку запуска или **F7**. Дождитесь сервера и двух окон игроков.
4. Соберите монету первым игроком. У него должно стать **5**, у второго — **0**; монета исчезнет в обоих окнах.
5. Попробуйте подбежать обоими игроками к одной монете: суммарная награда за одно появление — **5**, а не 10.
6. Купите улучшение первым игроком. Баланс, уровень и скорость второго должны остаться прежними. Цена в интерфейсе у каждого своя.
7. Завершите тест через **End Session**.

Подробнее о [режимах тестирования Studio](https://create.roblox.com/docs/studio/testing-modes).

## Как работать с другом

Когда локальная версия заработает, владелец может сохранить проект в свой аккаунт через **File → Publish to Roblox…**. Для совместной разработки игры откройте **Collaborate**, найдите Roblox-друга и назначьте ему доступ **Edit**, затем сохраните настройки. Для совместной проверки выберите **Team Test**: друг присоединяется через кнопку запуска в своём Studio.

Доступ к совместному редактированию зависит от настроек аккаунтов и текущих требований Roblox. Если Studio не даёт добавить друга, следуйте сообщениям в окне Collaborate и [официальной инструкции](https://create.roblox.com/docs/projects/collaboration).

Можно разделить работу: один меняет числа в `GameConfig` и проверяет покупки, второй оформляет арену в `Workspace → CoinSpeedWorld`. Размеры, цвета и положение деталей можно менять прямо в Studio при остановленном тесте. Изменения деталей в запущенном тесте исчезают после Stop.

## Как устроен код — простыми словами

- **GameConfig** — общая таблица настроек. Здесь цена монеты, цены покупок и прибавка скорости. `return Config` отдаёт таблицу другим скриптам.
- **GameServer** — общий «судья» для всех игроков. Подключает логику к готовой карте, считает деньги и разрешает покупки. Если вы вставляете только скрипты в новый проект, он создаёт недостающие детали сам. `Touched` сообщает о касании монеты, `Triggered` — о нажатии E у магазина.
- **GameHUD** — личный экран игрока. Он читает баланс и уровень и показывает их. Деньги этот скрипт не выдаёт.
- **leaderstats** — папка с числами, которые Roblox показывает в таблице игроков. `Coins` — текущий баланс, `SpeedLevel` — число купленных улучшений.
- **WalkSpeed** — настройка скорости персонажа. При покупке сервер меняет её, а при новом появлении персонажа применяет заново.
- **GameFeedback** — событие, которым сервер отправляет только нужному игроку сообщение об успешной покупке или нехватке монет.

Покупки и награды проверяются на сервере, в том числе по расстоянию до предмета. Такой подход соответствует [рекомендациям Roblox для взаимодействий клиента и сервера](https://create.roblox.com/docs/scripting/security/client-server-boundary).

## Что можно менять первым

Откройте `GameConfig` в Studio и поменяйте, например:

```lua
Config.CoinValue = 10          -- Теперь одна монета даёт 10.
Config.CoinRespawnSeconds = 3  -- Возвращается через 3 секунды.
Config.SpeedPerLevel = 6      -- Каждая покупка прибавляет 6 скорости.
```

Меняйте числа при остановленном тесте и запускайте снова. Для начала используйте положительные числа и целое `MaxSpeedLevel`.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Не видно арены | В готовом проекте выделите `Workspace → CoinSpeedWorld` и нажмите F. Если устанавливали только скрипты вручную, карта появится при F5 / Play. |
| `Infinite yield possible ... GameConfig` | В `ReplicatedStorage` должен быть **ModuleScript** с точным именем `GameConfig` и полным кодом из файла. |
| Карта есть, интерфейса нет | `GameHUD` должен быть **LocalScript** внутри `StarterPlayerScripts`; запускайте F5, а не F8 / Run. |
| Нет монет в таблице игроков | Проверьте сообщения Output: сервер должен создать папку с точным именем `leaderstats`. |
| Магазин не реагирует | Подойдите вплотную, дождитесь подсказки E, отпустите и нажмите E ещё раз. Между покупками есть пауза 0,5 секунды. |
| Появляетесь далеко от арены | В новом Baseplate-проекте оставьте только старт, создаваемый нашим скриптом. Остановите и снова запустите тест. |
| Изменения кода пропали | Редактируйте при остановленном тесте; сохраняйте проект через File. |
| Деньги пропали после выхода | В первой версии это ожидаемо. Следующим шагом можно добавить DataStore для сохранений. |

При ошибке скопируйте **первую красную строку из Output**, имя скрипта и номер строки — по ним можно точно найти причину.

## Файлы для разработки

Исходники в `src` и скрипты внутри `.rbxlx` — отдельные копии. Новичку проще редактировать проект прямо в Studio и сохранять его через File. Если меняете файлы в `src`, пересоберите проект командой `node tools/build-place.mjs` из этой папки (нужен Node.js). Пересборка заменит `CoinSprint.rbxlx` исходниками из `src` и стандартной картой, поэтому изменения, сделанные только внутри Studio, сначала сохраните в отдельный файл.
