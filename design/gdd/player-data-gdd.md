## 1. Overview & Purpose
Сохраняет прогресс игрока между заходами и защищает от потери и дублирования данных при переходе между серверами. Глобальные лидерборды (топ-100) дают соревновательную цель. `[ИЗ КОДА]`

## 2. Core Mechanics `[ИЗ КОДА]`
### Профиль
- Хранилище `CoinSprint_Profiles_V3`, ключ — `UserId`.
- Работает только в опубликованной игре. В Studio по умолчанию отключено (`EnableStudioDataStores=false`): HUD показывает «SESSION ONLY».
- **Блокировка сессии:** при загрузке в профиль пишутся `Session` (JobId сервера) и `Lease` (время). Если профиль занят другим сервером и аренде меньше 180 с, загрузка повторяется до 4 раз (паузы 2, 4, 6, 8 с), затем игрока выкидывают с просьбой перезайти.
- **Сохранение:** автосохранение каждые 60 с (продлевает аренду), сохранение при выходе (снимает блокировку), `BindToClose` — сохранение всех игроков при выключении сервера, до 25 с.
- Сохранение пишет данные, только если блокировка всё ещё принадлежит этому серверу.
- При загрузке все числа проверяются: не NaN, |x| < 1e15, не отрицательные, уровни приводятся к допустимым диапазонам.
- Пока профиль не загружен (`ProfileReady=false`), игровые remote не работают.

### Лидерборды
- Три доски, стоят в Meadow и Neon: TOP 100 COINS (`LifetimeEarned` × 100), TOP 100 EGGS (`EggsOpened`), TOP 100 PICKUPS (`CoinsCollected`).
- Хранилища `CoinSprint_TopV3_<Stat>` (OrderedDataStore). Значение только растёт (`max(старое, новое)`).
- Обновление раз в 120 с (в Studio — по игрокам сервера раз в 8 с).
- Пьедестал топ-3 показывает аватары лидеров.

## 3. Data Schema `[ИЗ КОДА]`
```
CoinSprint_Profiles_V3 / <UserId> = {
  Session: string?, Lease: number,              -- блокировка сессии
  Coins: number, Speed: int,
  MagnetLevel, IncomeLevel, DoubleLevel: int,
  Rebirths: int, PetLevel: int,
  LifetimeEarned, CoinsCollected, EggsOpened: number,
  Owned: { ["1".."81"]: int },
  AutoDelete: { ["1".."81"]: bool },
  Equipped: string,                             -- "12,5,5"
  Potions: { Coins, Speed, Luck: int },
  PotionLeft: { Coins, Speed, Luck: seconds },
  Badges: { [BadgeId]: bool },
  MagnetTier: int, MagnetEquipped: int,
  IndexClaimed: { ["1".."9"]: bool },
  DailyDay: int, DailyClaimedAt: unix,
}
CoinSprint_TopV3_LifetimeEarned / <UserId> = int (×100)
CoinSprint_TopV3_EggsOpened     / <UserId> = int
CoinSprint_TopV3_CoinsCollected / <UserId> = int
```
Поля `Version` в профиле нет: миграции схемы не предусмотрены, суффикс `_V3` в имени хранилища означает, что предыдущие версии просто брошены. `[ИЗ КОДА]`

## 4. Client-Server Split `[ИЗ КОДА]`
- Всё на сервере (`WorldProgress.server.luau`). Клиент видит данные через `leaderstats` и атрибуты игрока; `SaveStatus` выводится в HUD.

## 5. RemoteEvents/Functions `[ИЗ КОДА]`
Своих remote нет. Данные идут клиенту через реплицируемые атрибуты и `leaderstats`.

## 6. Player-Facing UI `[ИЗ КОДА]`
- Строка статуса в панели статистики: `LOADING PROFILE` / `SAVING ENABLED` / `SESSION ONLY` / `SAVE RETRY PENDING`.
- Сообщение при кике: «Your profile is unavailable or still open on another server. Please rejoin shortly.»
- Доски лидеров (SurfaceGui) с подписью «GLOBAL · refreshes every 120s» или «THIS SERVER …».

## 7. Edge Cases & Error States
1. **Быстрый переход на другой сервер:** старый сервер снимает блокировку при выходе; если не успел — новый ждёт до ~20 с, затем кик. `[ИЗ КОДА]`
2. **Старый сервер упал, не сняв блокировку:** профиль недоступен до 180 с после последнего автосохранения — игрок получит кик и должен подождать. `[ИЗ КОДА]`
3. **Ошибка сохранения при выходе:** записывается предупреждение, повтора нет; `sessions[p]` остаётся, и `BindToClose` попробует ещё раз при выключении. Повторить сохранение сразу? `[НУЖЕН ВАШ ОТВЕТ]`
4. **Повреждённые или подменённые числа в профиле:** приводятся к 0 или к допустимому диапазону. `[ИЗ КОДА]`
5. **Сервер выключается:** до 25 с на сохранение всех игроков. `[ИЗ КОДА]`
6. **DataStore недоступен при загрузке:** 4 попытки, затем кик (а не игра без сохранения). `[ИЗ КОДА]`
7. **Изменение каталога питомцев (новые id):** старые профили получат 0 для новых id, ничего не ломается. Удаление или перенумерация id сломает чужие коллекции. `[ИЗ КОДА]`
8. **Бюджет запросов:** при 12 игроках каждые 120 с идёт 36 `UpdateAsync` в OrderedDataStore + 12 автосохранений в минуту — в пределах лимитов Roblox. `[ИЗ КОДА]`

## 8. Balancing Parameters `[ИЗ КОДА]`
```
аренда_блокировки       = 180 с
автосохранение          = каждые 60 с
попытки_загрузки        = 4, пауза = 2 × номер_попытки с
лимит_BindToClose       = 25 с
обновление_лидербордов  = 120 с (опубликовано) / 8 с (Studio)
масштаб_LifetimeEarned  = ×100 (две цифры после запятой в целом числе)
```
