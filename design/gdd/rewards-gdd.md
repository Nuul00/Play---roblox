## 1. Overview & Purpose
Удержание: ежедневные награды дают повод заходить каждый день, достижения отмечают первые цели и навсегда немного повышают доход. `[ИЗ КОДА]`

## 2. Core Mechanics `[ИЗ КОДА]`
### Ежедневные награды
- Цикл из 7 дней. Награду можно забрать раз в 24 часа после предыдущей.
- После 7-го дня цикл начинается с 1-го.
- Пропуск дней **не сбрасывает** серию: следующий заход даёт следующий день цикла.

### Достижения
- 6 достижений, проверяются сервером раз в 0,5 с.
- Каждое навсегда даёт ×1,05 к монетам, бонусы перемножаются.

## 3. Data Schema `[ИЗ КОДА]`
| Поле профиля | Тип | По умолчанию | Описание |
|---|---|---|---|
| `DailyDay` | int 0–7 | 0 | последний полученный день |
| `DailyClaimedAt` | unix-время | 0 | когда получена последняя награда |
| `Badges.<Id>` | bool | false | достижение открыто |
| `LifetimeEarned`, `CoinsCollected`, `EggsOpened` | number | 0 | счётчики для условий |

Производные атрибуты: `BadgeBonus`, `PetsDiscovered`.

## 4. Client-Server Split `[ИЗ КОДА]`
- **Сервер:** проверка 24 часов, выдача, проверка условий достижений (`DailyRewards.server.luau`, `PlayerSystems.CheckBadges`).
- **Клиент:** окно календаря (`DailyUI`), уведомления о достижениях.
- **Общее:** `DailyConfig`, `ShopConfig.Badges`.

## 5. RemoteEvents/Functions `[ИЗ КОДА]`

## 6. Player-Facing UI `[ИЗ КОДА]`
- Окно с 7 днями, иконками наград, таймером до следующей.
- Уведомление при открытии достижения; список достижений в HUD/инвентаре.

## 7. Edge Cases & Error States
1. **Два запроса одновременно:** между проверкой и записью времени сервер не уступает управление, двойная выдача невозможна. `[ИЗ КОДА]`
2. **Игрок перевёл часы на устройстве:** время берётся с сервера (`os.time()`), не влияет. `[ИЗ КОДА]`
3. **Заход на разных серверах:** время получения хранится в профиле с блокировкой сессии. `[ИЗ КОДА]`
4. **DataStore недоступен (Studio):** награду можно получать раз в 24 часа только в пределах сессии.
5. **Пропуск недели:** серия не сбрасывается. Так задумано или нужен сброс к 1-му дню? `[НУЖЕН ВАШ ОТВЕТ]`
6. **Получение 7-й награды:** следующая снова 1-я, бонуса за полный круг нет. `[ИЗ КОДА]`

## 8. Balancing Parameters `[ИЗ КОДА]`
```
готово = DailyClaimedAt == 0  или  now ≥ DailyClaimedAt + 86 400
следующий_день = DailyDay mod 7 + 1
бонус_достижений = 1,05 ^ число_открытых            (максимум 1,05^6 ≈ 1,34)
```

| День | Награда |
|---|---|
| 1 | 1 000 монет |
| 2 | зелье удачи ×1 |
| 3 | 2 500 монет |
| 4 | зелье скорости ×2 |
| 5 | зелье монет ×2 |
| 6 | зелье удачи ×3 |
| 7 | 10 000 монет + по 1 зелью каждого вида |

| Достижение | Условие |
|---|---|
| First Steps | подобрать 100 монет |

Награды в монетах фиксированы: в Sky 10 000 монет — это меньше минуты игры.
